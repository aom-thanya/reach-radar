# ReachRadar — เอกสารโปรเจกต์

ReachRadar วิเคราะห์คนที่คอมเม้นใน YouTube รายการ **โหนกระแส** ปี 2026 ว่าเป็นใคร (Gen) มาบ่อยแค่ไหน (ความภักดี) และสนใจเรื่องแบบไหน (หมวดและประเด็นย่อย) ทีมการตลาดจะใช้ผลเป็นหลักฐานประกอบการขาย Slot โฆษณารายตอน

> โปรเจกต์เพื่อการศึกษา ใช้เครื่องมือฟรีทั้งหมด ไม่ใช้ API ที่เสียเงิน
