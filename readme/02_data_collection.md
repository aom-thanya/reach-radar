## ฟิลด์ที่ได้ต่อ 1 คอมเม้น
`cid`, `text`, `time` (เช่น "4 วันที่ผ่านมา"), `time_parsed`, `author` (handle), `channel` (ใช้เป็น id ของคน), `votes` (ไลก์บนคอมเม้น เช่น "1.2 พัน"), `replies`, `heart`, `reply`, `video_id`, `scraped_at`

## คุณภาพข้อมูล (ผลจาก EDA)
- ไม่มี `cid` ซ้ำ และไม่มีแถวที่ขาด channel id มีข้อความว่างแค่ 1 แถว
- ไม่มี EP ไหนดึงไม่สำเร็จ
- เวลาของคอมเม้นเป็นค่าโดยประมาณ เพราะ YouTube แสดงแค่ "x วัน / สัปดาห์ / เดือนที่แล้ว"
- ขนาดคอมเม้นดิบราว 520 MB เก็บในเครื่องเท่านั้น

## คำอธิบายคลิป (ตรวจหาสปอนเซอร์) · 22 พ.ย. 2569
- ดึงคำอธิบายคลิปครบ 227 EP ด้วย `13_descriptions.py` จากหน้าเว็บสาธารณะ ไม่ต้องล็อกอิน เก็บที่ `data/raw/descriptions.jsonl`
- **ทุก EP เป็นข้อความเดียวกัน** มีแค่เวลาออกอากาศ ลิงก์โซเชียลของรายการ และลิงก์ Membership ไม่มีชื่อแบรนด์ ลิงก์สินค้า หรือโค้ดส่วนลด
- คอมเม้นที่พูดถึงสปอนเซอร์ของรายการแทบไม่มี (เจอชื่อ GRD ครั้งเดียว) ส่วนใหญ่พูดถึงสปอนเซอร์ของแขก
- **สรุป:** ข้อมูลสาธารณะไม่บอกว่าแบรนด์ไหนลง EP ไหน ต้องขอตารางสปอนเซอร์จากทีมขายหรือช่อง 3

## ข้อความถอดเสียง (คำบรรยายอัตโนมัติภาษาไทย) · 22 พ.ย. 2569
- ทุก EP ที่ลองมีคำบรรยายไทยที่ YouTube สร้างอัตโนมัติ ดึงตรงๆ ได้ไฟล์ว่าง (ต้องมี token) จึงใช้ `youtube-transcript-api` (ฟรี) ผ่าน `16_transcripts.py`
- เก็บที่ `data/raw/transcripts/<video_id>.json` **ในเครื่องเท่านั้น** เป็นเนื้อหาลิขสิทธิ์ของรายการ ใช้วิเคราะห์ภายใน ห้ามเผยแพร่ข้อความ
- รอบแรกได้ 19 EP แล้วโดน YouTube บล็อก IP (`IpBlocked`) สคริปต์หยุดเองหลังล้มเหลว 5 ครั้งติด
- รอปลดบล็อกแบบช้า 4 รอบ (ราว 2 ชั่วโมง) ยังไม่หาย และลองแบบล็อกอินด้วย cookie ก็ยังโดนบล็อก เพราะบล็อกที่ระดับ IP ของเน็ต ต้องรอข้ามคืนหรือใช้เน็ตอื่น
- ที่เห็นจาก 19 EP: ท้ายรายการมีช่วงมอบของให้แขก พิธีกรอ่านชื่อสปอนเซอร์ เช่น ฮาชิ GRD Plus, M150, วิซี
