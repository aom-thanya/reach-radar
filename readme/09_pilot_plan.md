# 09 · แผน Pilot: วัด Conversion ตามสายคนดู (ร่าง)

> สถานะ: **ร่าง รอพี่อนุมัติ · ชุดอุปกรณ์พร้อมแล้ว (ข้อ 11)** · เขียน 22 พ.ย. 2569
> เป้าหมายคือเปลี่ยนจากการขาย "ความสนใจตรงกลุ่ม" ไปเป็นการขาย "ตัวเลข conversion ที่วัดได้จริง"

## 1. คำถามที่ Pilot ต้องตอบ
**EP ที่มีคนดูจากสาย X เยอะ ทำให้คนใช้โค้ดต่อ 1,000 วิวสูงกว่า EP ที่มีคนสาย X น้อยหรือไม่ และสูงกว่ากี่เท่า**

ต้องเขียนสมมติฐานไว้ก่อนเริ่มทุกครั้ง เพื่อไม่ให้ไปหาเรื่องที่บังเอิญดีขึ้นมาทีหลัง ตัวอย่าง:
> "สินค้า [ประกัน/ทนาย/ของใช้ในบ้าน] จะมีอัตราใช้โค้ดสูงขึ้นใน EP ที่มีคนสายครอบครัว-ชู้สาวเยอะ"

## 2. ขอบเขต
| เรื่อง | กำหนด | เหตุผล |
|---|---|---|

| รูปแบบโฆษณา | แบบเดียว ใช้สคริปต์เดิม ช่วงเวลาในรายการใกล้เคียงกันทุกครั้ง (เช่น พิธีกรพูดถึงช่วงพักแรก) | ตัดผลจากความต่างของรูปแบบโฆษณาออก |
| จำนวน EP | **60 EP ติดกัน** (ราว 12 สัปดาห์ เพราะรายการออก จ.–ศ.) | |
| EP ที่มีโฆษณา | **สุ่ม 40 จาก 60 EP** ด้วยการจับฉลากล่วงหน้า อีก 20 EP ไม่มีโฆษณา | EP ที่ไม่มีโฆษณาคือฐานเทียบ เพื่อดูว่าโฆษณาทำให้คนซื้อเพิ่มจริง ไม่ใช่ซื้ออยู่แล้ว |

**ทำไมต้องสุ่ม ไม่ให้ทีมขายเลือก EP เอง:** ถ้าทีมขายเลือกเฉพาะ EP ที่คาดว่าจะดัง ผลจะดีเพราะ EP ดัง ไม่ใช่เพราะสาย

### 3.3 ถ้าได้ (ไม่บังคับ)

- **แบบสอบถามตอนใช้โค้ด:** Google Forms ถามคำถามเดียวว่า "ปกติชอบดูโหนกระแสเรื่องแนวไหน" แล้วแปลงคำตอบเป็นสาย ช่วยยืนยันผลระดับคน แต่คนตอบจะน้อย

## 4. กติกาโค้ดและลิงก์
- **โค้ดไม่ซ้ำกันทุก EP** เช่น `HONE2301` ใช้ได้ 7 วันหลังออกอากาศ
  - ยอดใช้โค้ดจึงผูกกับ EP ได้ตรงๆ
- ลิงก์ UTM ต่อ EP เช่น `utm_source=youtube&utm_campaign=hone&utm_content=ep2301` วางในคำอธิบายคลิปและคอมเม้นปักหมุด
- ส่วนลดเท่ากันทุกโค้ด
- คอยดูว่าโค้ดหลุดไปเว็บรวมคูปองหรือไม่ ถ้าโค้ดไหนถูกใช้หลังวันที่ 7 เยอะผิดปกติ ให้ติดธงไว้ตอนวิเคราะห์

## 5. วิธีวิเคราะห์
1. **โฆษณาได้ผลไหม (ภาพรวม):** เทียบยอดขายรวมรายวันหลัง EP ที่มีโฆษณา กับหลัง EP ที่ไม่มีโฆษณา
2. **สายไหนได้ผลดี (คำถามหลัก):** ใช้ 40 EP ที่มีโฆษณา
   - ตัวแปรตาม = ยอดใช้โค้ด
   - ตัวแปรหลัก = % ของคนสายที่ตั้งสมมติฐานไว้ใน EP นั้น
   - ใช้ **Negative Binomial regression** โดยใส่ log(ยอดวิว) เป็น offset เพื่อให้เป็น "ต่อ 1,000 วิว"
     - เหตุผล: ยอดใช้โค้ดเป็นค่านับ และแต่ละ EP แกว่งมากกว่าที่ Poisson คาดไว้
   - คุมตัวแปรอื่น: วันในสัปดาห์ และ % แฟนตัวยง (เพราะแฟนตัวยงอาจซื้อมากกว่าอยู่แล้ว)
   - รายงานเป็น "เท่า" พร้อมช่วงความเชื่อมั่น 95%
3. **ตารางอ่านง่ายสำหรับแบรนด์:** แบ่ง EP เป็น 3 กลุ่มตาม % ของสาย (มาก / กลาง / น้อย) แล้วแสดงยอดใช้โค้ดต่อ 1,000 วิวของแต่ละกลุ่ม
4. **ตัวชี้วัดรอง:** คลิกต่อ 1,000 วิว, ยอดขายต่อ 1,000 วิว, คอมเม้นที่พูดถึงแบรนด์

**ข้อจำกัดที่ต้องบอกแบรนด์:** ผลนี้เป็นระดับ EP คือ "EP ที่มีสายนี้เยอะขายได้ดี" ไม่ได้พิสูจน์ว่า "คนสายนี้ทุกคนซื้อมากกว่า"

## 6. จำนวน EP พอไหม
- **สมมติ** ว่า EP หนึ่งมีคนใช้โค้ดราว 50 ครั้ง (ยังไม่รู้ตัวเลขจริง)
- 40 EP ที่มีโฆษณา แบ่งเป็นกลุ่มสายมากและสายน้อยกลุ่มละราว 13 EP พอจะเห็นความต่างประมาณ **1.5 เท่าขึ้นไป**
- ถ้าต่างกันน้อยกว่านั้น จะยังสรุปไม่ได้
- **จุดตรวจสัปดาห์ที่ 4:** ใช้ตัวเลขจริงคำนวณใหม่
  - ถ้ายอดใช้โค้ดต่ำกว่า 20 ครั้งต่อ EP: ขยายเป็น 80 EP หรือเพิ่มส่วนลด
  - ถ้า % ของสายใน EP ต่างกันน้อยเกินไป: ขยายเวลาออกไป

## 7. เกณฑ์ตัดสินใจ (ตกลงกันก่อนเริ่ม)
| ผล | สิ่งที่ทำต่อ |
|---|---|
| สายที่ตั้งสมมติฐานไว้ได้ผล ≥ 1.5 เท่า และช่วงความเชื่อมั่นไม่คร่อม 1 | ใช้เป็นตัวเลขขายได้ ทำแพ็กเกจราคาตามสาย |
| ทิศทางถูก แต่ช่วงความเชื่อมั่นคร่อม 1 | ยังขายเป็นตัวเลขไม่ได้ ทำรอบสองกับสินค้าเดิมเพื่อเพิ่ม EP |
| ไม่ต่างกัน | ขายแบบความสนใจตรงกลุ่มต่อไป และบอกแบรนด์ตรงๆ ว่า conversion ไม่ขึ้นกับสาย |

## 9. ความเสี่ยง
| ความเสี่ยง | ทางแก้ |
