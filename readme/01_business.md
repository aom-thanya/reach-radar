# 01 · Business

## ปัญหาที่ต้องการแก้
ทีมขายโฆษณาของรายการโหนกระแสยังไม่มีข้อมูลยืนยันว่า "คนที่ดูเรื่องแบบนี้เป็นใคร" ตอนเสนอขาย Slot รายตอนให้แบรนด์จึงพูดได้แค่ยอดวิว
ReachRadar จึงใช้คนที่คอมเม้นเป็นตัวแทนผู้ชมที่มีส่วนร่วม (engaged audience) แล้วตอบว่า
- ผู้ชมแต่ละหมวดและประเด็น **อยู่ Gen ไหน**
- เป็น **แฟนประจำหรือคนผ่านมา**
- **มีปฏิกิริยาแบบไหน** เช่น ดูเยอะ ไลก์เยอะ หรือถกเถียงเยอะ

## เป้าหมายธุรกิจ
1. **จับคู่แบรนด์กับคอนเทนต์:** แบรนด์ที่เจาะ Gen ใด ควรลงหมวดหรือประเด็นไหน ดูจากค่า lift ของ Gen
2. **ตั้งราคา Slot:** ตอนไหนมีมูลค่าสูง เช่น ตอนแรกของซีรีส์ หรือตอนที่คู่กรณีมาเผชิญหน้ากัน
3. **เลือกแพ็กเกจตามเป้าหมายแคมเปญ**
   - เน้นการเข้าถึงคนจำนวนมาก (Reach) → ประเด็นที่ยอดวิวสูงและมีขาจรเยอะ
   - เน้นการมีส่วนร่วม (Engagement) → ประเด็นที่อัตราคอมเม้นสูง
   - เน้นฐานแฟน (Loyalty) → ประเด็นที่มีแฟนตัวยงสัดส่วนสูง
4. **ความปลอดภัยของภาพลักษณ์แบรนด์ (Brand safety):** ระบุประเด็นอ่อนไหว เช่น คดีทางเพศ หรือมีคนเสียชีวิต เพื่อให้แบรนด์เลือกได้เอง

## ผู้ใช้หลัก

| ผู้ใช้ | ต้องการอะไร | ใช้ส่วนไหน |
|---|---|---|
| **ทีมขาย / AE** (ผู้ใช้หลัก) | ตัวเลขสั้นๆ ที่หยิบไปใส่ Proposal ได้ทันที | Dashboard: หมวด → ประเด็น → Gen / ความภักดี / Engagement |
| **ทีมการตลาด / Planner** | เปรียบเทียบหมวดและประเด็น เพื่อออกแบบแพ็กเกจ | Heatmap lift, ตารางประเด็นย่อย, ซีรีส์ |
| **นักวิเคราะห์ (เจ้าของโปรเจกต์)** | อัปเดตข้อมูล ตรวจวิธีคิด และรันซ้ำ | สคริปต์ใน `scripts/` และเอกสารชุดนี้ |

## User Journey (ทีมขาย)
1. **รับโจทย์:** แบรนด์บอกกลุ่มเป้าหมาย เช่น "Gen Y ผู้หญิง สนใจเรื่องครอบครัว" และงบประมาณ
2. **เปิด Dashboard:** ดูเรดาร์ผู้ชมว่าหมวดไหน Gen นั้น lift สูง
3. **เจาะประเด็นย่อย:** เช่น ครอบครัว × ชู้สาว เทียบกับครอบครัว × มรดก แล้วดูวิว อัตราไลก์ อัตราคอมเม้น และสัดส่วนแฟนกับขาจร
4. **เลือกตอน:** ดูตาราง EP และซีรีส์ เพื่อเลือกตอนที่ตรงประเด็น เช่น จองตอนแรกของซีรีส์ใหม่
5. **ทำ Proposal:** คัดลอกตัวเลขพร้อมช่วงความเชื่อมั่นและหมายเหตุวิธีคิด
6. **หลังแคมเปญ:** เทียบผลจริงกับที่คาด แล้วแจ้งนักวิเคราะห์เพื่อปรับปรุง

## คำถามที่ระบบต้องตอบ
- หมวดและประเด็นย่อยแต่ละแบบ มีสัดส่วน Gen Baby Boomer / X / Y / Z เท่าไหร่ และ Gen ไหน lift สูงกว่าปกติ
- คนดูแต่ละหมวดเป็นแฟนตัวยง นักเสพข่าว หรือขาจร กี่คนและกี่ %
- ประเด็นไหนดูเยอะ ไลก์เยอะ หรือคอมเม้นเยอะ เทียบกับเรื่องอื่นในหมวดเดียวกัน
- คนดูหมวดหนึ่งไปดูหมวดอื่นด้วยไหม ดูได้จาก Network คนดูร่วม และ Community ความสนใจ
- ซีรีส์ตอนไหนคุ้มค่าที่สุด

## สิ่งที่โปรเจกต์นี้ไม่ได้ตอบ
- อายุจริงหรือเพศจริงของผู้ชม เพราะทีมไม่มีสิทธิ์เข้า YouTube Studio
- คนที่ดูแต่ไม่คอมเม้น ซึ่งเป็นคนส่วนใหญ่
- ผู้ชมบน Facebook, TikTok และทีวี

### รอบปรับจากความเห็นผู้ใช้ (22 พ.ย. 2569)
- หน้าแรกมีปุ่มใหญ่ "มีโจทย์ลูกค้า? เริ่มที่นี่" ไปหน้าวางแผนแคมเปญ
- ตัวเลขเทียบปกติเขียนเป็น "+4%" / "−10%" / "3.2 เท่า" แทน ×1.04
- หน้าจับคู่แบรนด์ × Gen มีกล่อง "อ่านก่อนใช้": วัยต่างกันระหว่างหมวดไม่เกินราว ±10% ให้ดูสายความสนใจเป็นหลัก
- หน้าที่ใช้ข้อมูลทั้งปีมีป้ายบอกว่าตัวกรองหน้าภาพรวมไม่มีผล · ตาราง EP ในภาพรวมกรองตามตัวกรอง
- หน้า "หมวดและ EP" รวมเข้าภาพรวม (ส่วน "ข้อมูลละเอียด") · ปุ่ม "?" มีพื้นที่กดกว้างขึ้น
- **รายงานวางแผนแคมเปญเขียนใหม่ให้อ่านง่าย:** กล่อง "คำแนะนำ" อยู่บนสุด (ลงกี่ EP หมวดไหน + 4 ตัวเลข) → 1. ลงหมวดไหนและทำไม (เหตุผลเป็นประโยค + ปกและ EP ตัวอย่าง 3 ตอนที่กดเปิด YouTube ได้) → 2. คนที่จะเห็นเป็นใคร → 3. ถ้าโฆษณาแบบที่เลือก คนจะพูดถึงยังไง (สิ่งที่คาดว่าจะเกิดในคอมเม้น จำนวนคอมเม้นที่น่าจะพูดถึงสินค้า หลักฐานจริง คำแนะนำ ตารางเทียบ 3 รูปแบบ) → 4. Brand safety → 5. Conversion → ข้อควรรู้
